Multi OBS Controller - General Configuration
OBS Websocket Servers settings

Multi OBS Controller plugin communicates with OBS Studio via OBS Websockets.
Follow these steps to configure the Websockets Server for each instance of OBS Studio:

1. Open OBS Studio and go to Tools > Websocket Server Settings
2. Check "Enable Websocket Server"
3. Configure the Server Port and Server Password
4. Apply and close the settings window

Once the Websocket Servers are configured, add here their settings:

Mark a server as "IRLTK" if it's managed by IRLToolkit. IRLTK-marked servers are the only ones offered as a target for IRLToolkit actions (Ingest Status/Volume), and are hidden as targets for actions IRLToolkit itself disables manual control of (record, stream, replay buffer, virtual cam, profile switching, capture device refresh).

Pinned Ingests

Ingest names (as shown in IRLToolkit) always sorted first, in this order, when using dynamic ingest position targeting.

IRLToolkit Ingests

Optional display name override and category for each IRLToolkit ingest. The alias is shown wherever an ingest name appears (e.g. the Ingest Volume dial). The category groups dynamic ingest position targeting (Backpack, then Phone, then Desktop, then uncategorized). Both apply everywhere, matched by the ingest's OBS source name so they survive IRLToolkit renames.

Scene Name Aliases

Optional display name overrides for scenes, shown wherever a scene name appears (e.g. the Scene Preview dial). Applies everywhere.
