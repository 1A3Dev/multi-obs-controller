How to set up OBS Websocket servers

Multi OBS Controller plugin communicates with OBS Studio via OBS Websockets.
Follow these steps to configure the Websockets Server for each instance of OBS Studio:

1. Open OBS Studio and go to Tools > Websocket Server Settings
2. Check "Enable Websocket Server"
3. Configure the Server Port and Server Password
4. Apply and close the settings window

Once the Websocket Servers are configured, add their settings below.

About IRLToolkit-managed servers

Mark a server as "Managed by IRLToolkit" if it's managed by IRLToolkit. IRLTK-marked servers are the only ones offered as a target for IRLToolkit actions (Ingest Status/Volume/Scene), and are hidden as targets for actions IRLToolkit itself disables manual control of (record, stream, replay buffer, virtual cam, profile switching, capture device refresh). Each IRLTK-marked server also gets its own Ingest → Scene Mapping, used by the IRLToolkit Ingest Scene action to look up which scene to switch to for a given ingest on that server (ingest and scene names can differ between servers).

Set a Streamer name to fill the server's Pinned Ingests and Ingest Aliases & Categories from that streamer's settings (1a3.uk userscript settings). While a streamer is set those lists are read-only - use Refresh (or Refresh all streamers) to pull the latest, or clear the Streamer name to edit them by hand.
